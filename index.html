ABOUT THIS INDEX

One index. Two collections.

Identical contents are grouped by SHA-256, with every archive path retained. Results include verified hashes and MIDlet manifest metadata loaded on demand.

Verification
Both SHA-1 and SHA-256 were calculated from real extracted file bytes, with one path-too-long case streamed directly from 7z. File sizes and CRC32 were checked.

Downloads
The original files are hosted by Internet Archive. Archive member links rely on Internet Archive. Original collection source locations are historical provenance and are not necessarily downloadable links.
