ABOUT THIS INDEX

One index. Two collections.

Identical content is grouped by SHA-256, while every original archive path remains visible. The source collection is indicated for every file.

Verification
Both SHA-1 and SHA-256 were calculated from real extracted file bytes, with one path-too-long case streamed directly from 7z. File sizes and CRC32 were checked.

Downloads
The original files are hosted by Internet Archive. Archive member links use Internet Archive's archive viewer and may depend on its availability.
