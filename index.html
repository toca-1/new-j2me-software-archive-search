HOW RECOVERY WORKS

No full archive download required

The compressed archive contains 63 independently decompressible solid blocks. A recovery helper downloads just the volumes containing the selected block, plus the volumes needed for the archive metadata. Missing volumes are represented by sparse files, then the extracted file is checked against its SHA-1.

1 Find your file and copy its recovery command.
2 Install python3, curl, and 7zip on Linux.
3 Run the command; the helper downloads, extracts, and verifies the file.
