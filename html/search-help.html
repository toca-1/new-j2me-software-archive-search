Search help

Text

This search mode returns results containing every word of your search. It also supports special syntax, like:

  • -[WORD] Exclude any result containing the word.
  • "WORD1 WORD2" Only show results containing the exact phrase.

Examples

prince -persia
prince of persia
"prince of persia"
"test game" -demo
sonic -panasonic

The main Text search needs an included word of at least two characters. Searches containing exclusions only can be entered in Search within results.

Hash

Enter a complete 8-, 40- or 64-character hexadecimal hash (CRC32, SHA-1 or SHA-256). SHA hashes identify specific file contents; CRC32 may match more than one file.
